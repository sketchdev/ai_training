# LAB-07: Accuracy statistics

Size: M

As a player, I want to know how accurate I am.

Acceptance criteria:
- `GameView` includes `stats` with `playerShots`, `playerHits`, `computerShots`, and `computerHits`.
- When no shots have been fired, the counts are 0.
- Counts stay correct when a ship sinks.
- Tests cover a new game and a game with mixed hits and misses.

Depends on: LAB-06 is helpful but not required.
