# Day 1: Claude Code fundamentals

## Commands used in this course

| Command | Use |
|---|---|
| `/init` | Create a first `CLAUDE.md` for the repository |
| `/context` | Show what fills the context window |
| `/clear` | Start fresh and drop the history |
| `/compact` | Summarize the history to free space |
| `/usage` | Show session cost and plan limits |
| `/insights` | Make an HTML report on how you work |
| `/btw` | Ask a side question without adding to the main task |

## Keys

| Key | Use |
|---|---|
| `Esc` | Stop Claude |
| `Ctrl+O` | Show the transcript |
| `Ctrl+T` | Show the task list |

## Habits

- Give a brief, not a wish. Name the file, the symptom, and what "fixed" means.
- Use plan mode for work that touches several files. Read the plan and change it.
- Keep `CLAUDE.md` short. For each line ask: if I removed it, would Claude make a mistake?
- Use a fresh session for review. Claude should not grade its own work in the same context.
- Ask Claude to prove the change: tests, command output, a diff.
